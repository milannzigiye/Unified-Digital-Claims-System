# Implementation Notes

This file records the current implementation shape for reviewers and future maintainers.

## Design System

Shared styling lives in `assets/css/`.

- `tokens.css` defines BK color tokens, spacing, shadows, and base variables.
- `input.css` is the Tailwind input file.
- `output.css` is generated by `npm run build:css`.
- `global.css`, `role-pages.css`, and `app-overrides.css` hold app-level refinements.

Shared PHP UI helpers live in `components/`:

- `head.php`
- `role_nav.php`
- `button.php`
- `alert.php`
- `claims_list_ui.php`
- `claim_v2_detail_view.php`
- `pdf_report_theme.php`

## Claim Model and Workflow

Primary claim logic is split across:

- `Claimant/form_v2.php` for claimant intake and correction flow.
- `components/claim_documents.php` for document validation, staging, and protected storage helpers.
- `components/claims_v2.php` for claim schema support, people/assets/documents helpers, cleanup, and labels.
- `components/workflow.php` for status movement and assignment behavior.
- `components/claim_v2_detail_view.php` for the shared review surface.

## Review Pages

The main claims review pages are:

- `Admin/claims.php`
- `Legal/claims.php`
- `Finance/claims.php`

They use scan-first zebra tables with expandable detail bands. Full claim review is loaded through the shared claim detail view.

## Dashboards

Current dashboards are role-specific:

- Claimant: action needed, recent claims, claim health.
- Admin: system pressure, priority claims, activity, oversight.
- Legal: pending legal pressure, manual review, legal risks, assigned queue.
- Finance: verification readiness, settlement risk, assigned value, finance queue.

## Document Security

Claim documents are not meant to be opened through direct `uploads/...` links. The controlled gateway is:

```text
document_access.php
```

Access is checked by role and claim entitlement before streaming a file.

## PDF Exports

PDF exports use `components/pdf_report_theme.php`.

The current header standard is:

- logo
- `UNIFIED DIGITAL CLAIMS SYSTEM`
- `Bank of Kigali`
- report name
- generated timestamp
- `Filtered by: ...` when filters are active
